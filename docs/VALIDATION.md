# 検証範囲

通信・データ変換・設定操作・ファイル処理・GUI状態遷移を、自動テストと仮想シリアルで確認しています。

2026-11-01: 55テスト成功。ソースからのデモ起動とGUI表示を確認済みです。

## 自動テスト

- 通信フレームのチェックサム、断片受信、ノイズ、ID・長さの検証。
- 接続だけでは書き込まないこと、ID検索、モデルとプロファイルの選択。
- Write / Sync Write / Reg Write / Action、トルクOFFの部分失敗、設定ロック復元、ID・速度変更。
- xdatのバイト単位round-trip、モデル・FW一致、差分適用と部分失敗。
- CSVの列・単位、TXTのヘッダー・連番・末尾END・CRLF、複数回の追記保存。
- HEXのチェックサム・EOF・アドレス検証。
- 自動動作の範囲、停止、応答時間統計。
- Qt画面の検索・選択・設定表示・送信・終了、暗黙のスライダー送信の禁止、未知FWの書込禁止。
- 仕様と実装・テストの対応、および生成文書の一致。

実行コマンド:

```sh
PYTHONPATH=src QT_QPA_PLATFORM=offscreen /usr/bin/python3 -m unittest discover -s tests -v
```

通信の検証ベクトルは `spec/protocol.json`、ファイルとパケットのテストデータは `tests/fixtures/` にあります。

## 確認できる範囲

独立した仮想シリアル応答器へpyserialで接続し、検索・読取・Write・Sync Write・Reg Write / Action・EPROM設定を確認しています。デモモードとQtのオフスクリーン起動を検査しています。

## 実機での確認が必要な範囲

物理サーボの位置・速度・トルク、温度・電流の精度、実USBの遅延・切断時動作、EEPROMの電源断後保持、校正・Recovery・PWM波形は未検証です。仮想シリアルやデモでの成功は、実機での成功を保証しません。

xdatはSTS設定領域の保存・復元に対応します。他ソフトウェアとの往復読込は未検証です。ファームウェア転送は提供していません。
