# 操作ガイド

PortとBaudを選び、Open、Searchの順に操作します。サーボを選ぶと、Programmingでレジスタ、Debugでフィードバックと動作指令を扱えます。実機なしで試す場合は接続前にデモを選びます。

Liveは初期ONです。位置スライダーを動かすと指令を送ります。値を決めてから送信したい場合はLiveをOFFにします。動作指令とトルクONは別操作です。

Writeは選択したサーボへ順に送信します。Sync Writeは選択したサーボへ1フレームで送ります。Reg Writeはサーボへ指令を登録し、Actionで実行します。Actionは同じバス上で他のアプリが登録した指令にも影響します。

STOPは選択中と過去に指令を送ったサーボへトルクOFFを要求します。監視・記録は続きます。実行中のシリアル要求への割込みや登録済み指令の消去は行いません。トルクOFFを確認できなかったIDは表示に残ります。

SweepはStartとEndを往復します。Stepは指定量ずつ進め、端点を跨いでから折り返すため、Start/Endの範囲外への指令を含みます。自動動作は一定の待ち時間で次を送り、実際の位置到達は待ちません。

EEPROMはトルクOFFで編集し、書込後に読み戻します。復元途中で失敗しても、既に書き込んだ値は巻き戻しません。IDやBaudを変更すると、次回接続時の指定も変更する必要があります。

Time・電流・負荷には機種に依存するraw値を使います。CSVでは欠測を0に置き換えません。ファームウェア検査はファイルの確認だけで、サーボへの書き込みは行いません。
