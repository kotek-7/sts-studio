# Security reports

For a vulnerability that should not be public yet, email scpktk@gmail.com with the affected version, impact, and reproduction steps. Do not include credentials or private device data. Please allow time for a response before posting the details publicly.

Ordinary application bugs belong in [Issues](https://github.com/kotek-7/sts-studio/issues). Only the latest release receives fixes; update before checking whether a reported issue still occurs.
